**Why:** re-showing accepted screens costs review time and adds nothing; the record (decisions file) is what keeps them.

**How to apply:** each new explorer round draws only the screens that are new or changed since the last verdict, and links back to the decisions file for the rest. If an artifact belongs to another Claude account (the user switches accounts), publish a new one and note the old link; don't ask them to switch back.
