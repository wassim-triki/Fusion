The board groups open work by kind, inside each lane: **Big features** (projects of their own, wow features: product tour, AI assistant, landing page, languages, configurability, AI job families), **Polish** (visible fixes on existing screens), **Before hosting** (security and scale that don't show in the demo), **Cleanup and tooling**, **Parked**. Related small items get a parent (e.g. B-324 administrator leftovers).

**Why:** the user (2026-11-08) rejected an "Essentials / The rest" split, then asked that big features like the tour and the RAG assistant have their own category and the board be consolidated into cleaner categories. What the demo shows and people engage with matters most ([[graduation-demo-and-report]]).

**How to apply:** file every new item into one of these groups; never call a group "core" (confused with the Core HR module); keep the lanes (In progress, In review, Ready, Needs discussion) as they are.
